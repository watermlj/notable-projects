# Notable Projects
| **Project** | **Environment** | **Languages/Tools** | **Summary** |
| :--- | :--- | :--- | :--- |
| **Seven-Segment Encoder Counter** | Cora-Z707S FPGA | VHDL, Vivado | Encoder may be turned clockwise to increase the number on the four-digit seven-segment display by one. Minimum of 0000, maximum of 9999. Number can be reset by pressing the encoder down like a button. |
